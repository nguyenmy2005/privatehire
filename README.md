# PrivateHire Cars

Web đặt xe minicab ở London (Next.js + React + Tailwind, dữ liệu lưu trong localStorage).

```bash
npm install
```
```bash
npm run dev
```

Mở http://localhost:3000.

Code được tách theo **MVC** (`models/` → `controllers/` → `app/` + `components/`). Phân công Mỹ / Linh và quy trình làm chung: xem [CONTRIBUTING.md](CONTRIBUTING.md).
